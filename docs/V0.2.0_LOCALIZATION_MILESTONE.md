# v0.2.0 Localization Milestone

Status: **Implementation complete — release blocked on external gates**

Started: 2026-08-15

Release decision: pending owner review

This milestone prepares ten built-in interface locales for a possible `v0.2.0`
release. No tag, npm publication, or GitHub Release should be created until the
owner reviews this evidence and explicitly approves publication.

## Scope

### 1. Translation terminology review

- [x] Compare picker terminology with MUI X and other primary open-source
      implementations.
- [x] Record the official source links and concrete terminology findings.
- [x] Apply justified corrections to built-in translations.
- [x] Record which translations still require a fluent or native reviewer.

Evidence: [localization reference research](LOCALIZATION_REFERENCE_RESEARCH.md)
and `src/locales.ts`.

### 2. Long-label and responsive behavior

- [x] Exercise the longest built-in labels at mobile width.
- [x] Verify the popover and action controls do not overflow horizontally.
- [x] Verify long labels remain readable at narrow and wide layouts.
- [ ] Run the committed Windows visual baselines before release.

### 3. Locale matching and invalid values

- [x] Match supported regional variants to built-in interface wording.
- [x] Distinguish Traditional and Simplified Chinese script/region tags.
- [x] Preserve valid unsupported locales for `Intl` formatting while using
      English interface wording.
- [x] Canonicalize valid locale tags.
- [x] Fall back to `en-US` formatting and wording for invalid locale tags.

### 4. All-locale browser coverage

- [x] Add component coverage for all ten exact built-in locale tags.
- [x] Add component coverage for representative regional variants.
- [x] Exercise all ten locale options through the production demo.
- [x] Verify calendar, field, navigation, and action labels after switching.

### 5. Public and npm documentation

- [x] Document fixed and runtime language switching.
- [x] Link localization guidance from the README displayed on npm.
- [x] Include the localization guide, terminology research, and this milestone
      in the npm tarball.
- [x] Align `CONTEXT.md`, `PUBLIC_API.md`, README, and generated declarations.
- [x] Inspect `npm pack --dry-run` and packed React 18/19 consumers.

## Release decision gate

Before recommending publication:

- [ ] All five scope sections above are complete or have an explicitly accepted
      limitation.
- [x] `npm run check` passes.
- [x] Chromium, Firefox, and WebKit E2E pass in the release environment.
- [ ] Windows desktop and mobile visual baselines pass without unreviewed
      changes.
- [x] Packed React 18 and React 19 consumers pass.
- [x] The npm tarball contains the localization guide, research, and milestone
      documents.
- [ ] The owner reviews translation caveats, bundle growth, and release notes.
- [ ] The owner explicitly approves creating the immutable `v0.2.0` tag.

## Out of scope

RTL layout, localized editable date syntax, disabled-date callbacks, time-zone
search, native form serialization, and locale chunk splitting remain separate
future decisions. They are intentionally excluded so this milestone has one
clear purpose.
